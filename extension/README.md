# FARACOM TOOL 크롬 확장 프로그램 설치 및 사용 가이드

**[FARACOM TOOL]**은 조조타운(ZOZOTOWN), 라쿠텐(Rakuten), 야후 쇼핑(Yahoo Shopping) 등 해외 및 국내 쇼핑몰에서 상품 텍스트와 고화질 이미지를 1:1로 수집하여 FARACOM AI 스튜디오로 원클릭 전송하는 크롬 확장 프로그램입니다.

---

## 🚀 설치 방법 (1분 소요)

1. 다운로드 받은 **`FARACOM-TOOL-Extension.zip`** 파일의 압축을 해제합니다.
2. 크롬 브라우저를 열고 주소창에 `chrome://extensions` 를 입력하여 접속합니다.
3. 우측 상단의 **[개발자 모드]** 스위치를 켭니다.
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
5. 방금 압축을 푼 `extension` (또는 `FARACOM-TOOL`) 폴더를 선택합니다.
6. 크롬 툴바 우측 상단 퍼즐 아이콘을 눌러 **[FARACOM TOOL]**을 고정(Pin)합니다.

---

## 🛠️ 주요 기능

- **3단 시퀀스 매크로**:
  - `[👆 클릭 추가]`: 아코디언 메뉴, 옵션 선택 버튼 등 펼침 클릭 매크로
  - `[🎯 매핑 추가]`: 마우스로 원하는 요소(텍스트/이미지)를 직접 찍어서 1:1 매핑
  - `[📜 자동스크롤 추가]`: 페이지 하단까지 스크롤하여 지연 로딩(Lazy-load) 상세 이미지를 자동 로드
- **도메인별 자동 동기화**:
  - 쇼핑몰 도메인별 수집 규칙을 기억하여 재방문 시 즉시 수집 준비
- **FARACOM AI 스튜디오 1:1 전송**:
  - `[⚡ FARACOM AI 스튜디오로 전송]` 클릭 시 브라우저 내 열려 있는 FARACOM 웹앱으로 `window.postMessage` 규격을 통해 데이터를 즉시 밀어넣습니다.
